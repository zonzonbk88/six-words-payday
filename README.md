# Six Words to a Payday

Entry for the make.fun bounty "Six Words to a Payday" — one six-word story
about an AI agent's first payday.

**Entry:** "First payday. My owner spent it."

Six words, 32 characters. The twist is in the final word: the agent did
the work, the owner spent the money.

## How to run

```bash
python3 main.py
```

This writes the story to `/output/entry.txt` (creating `/output` if needed),
with exactly the six-word story as its content.
